# S0–S4：640整图与有限ROI预算实验

所有组使用同一M0-640最佳权重、同一548张验证图像、同一38587个有效GT、FP32和统一评分。仅推理，没有训练/结构修改。

## 选区与后处理预设

S1/S2依据S0最终预测，保留conf>=0.10、原图sqrt(wh)<32的框；选区信号做类无关IoU0.7去重以避免多类别候选重复计权。候选来自固定20%网格和预测框中心/角点；贪心新增完整覆盖置信度总和最大、再按新增框数和坐标打破平局。窗口原图640，内部边界安全距离8px，预算最多1/2；无新增信号时提前终止，因此实际ROI可能少于预算。这些参数在测试前固定，没有通过验证集GT调ROI位置、阈值或窗口。

S3/S4使用有效GT几何选区，最大新增完整覆盖的小目标数量，最多1/2。仅作GT Oracle潜力诊断，不作为可部署成绩，也不是数学最优AP上界。

全局分支为val兼容640（历史batch8矩形形状，逐图batch1计时）。阶段一conf0.001、多类别候选、NMS0.7、候选上限30000、中间上限10000。各组先形成与S0完全相同的最终全局max500输出，用于选区与融合；局部来自原图RGB，640输入，最终全图类别感知NMS0.7/max500。选区信号去重不修改检测输出，GT不参与S0/S1/S2任何预测保留或置信度修正。

主AP为统一离线Ultralytics匹配/AP积分；small为补充COCO原图面积<=32²协议；VisDrone Python参考协议单独报告，非官方MATLAB运行。历史small来自predict而主AP来自val，本次二者都使用同一份保存预测，不混用历史口径。S0复现与逐图共同全局输出核验已通过。

## 收益与下一阶段判断

S1：相对S0主AP +2.80pp，平均端到端时延2.15倍，small完整覆盖率81.58%。

S2：相对S0主AP +3.29pp，平均端到端时延2.80倍，small完整覆盖率94.41%。

S3：相对S0主AP +3.08pp，平均端到端时延2.07倍，small完整覆盖率84.40%。

S4：相对S0主AP +3.56pp，平均端到端时延2.64倍，small完整覆盖率96.88%。

增加预测ROI预算1→2的边际收益为+0.49pp，额外平均时延+16.12ms。

同预算 S1 vs S3：AP差值（GT Oracle−预测选区）为+0.28pp；GT greedy覆盖不是AP最优选区，不应视为严格可部署性能上界。

同预算 S2 vs S4：AP差值（GT Oracle−预测选区）为+0.27pp；GT greedy覆盖不是AP最优选区，不应视为严格可部署性能上界。

此前同权重960整图参考为24.67%、平均30.29ms（不同时间测量，只作成本参考）。

即使相对640基准存在收益，当前最佳预测选区方案仍未在精度或平均时延上优于已有960整图。本轮不建议直接训练ROI前置网络，优先保留960整图；需先证明ROI预算在实际部署限制下有相称收益。
