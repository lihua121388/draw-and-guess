## 跨ROI检查对优先级的意义

E3最终conf≥.25局部框：无观测20358个（70.97%，TP率64.80%）；有观测无支持210个（0.73%，TP率20.95%）；有支持8117个（28.30%，TP率62.56%）。支持使用另一ROI完整覆盖+8px安全边距、同类IoU≥.5及支持置信度≥.10，均在诊断前固定。几何机会不低，但最终无支持候选很少；C4不能预期仅靠删除这种反证框获得很大整体AP收益，也不应将“无观测”压低为不可靠。

以上是验证集事后诊断，不是C4训练标签或开发数据，不能据这些数值调整ρ、β、支持阈值或网络。原始候选池和最终输出的重复FP口径不同，完整计数/几何有效率必须一同看，不能只选有利的TP率。

4. 当前不允许重训YOLO或质量器，因此完整交叉拟合未执行。拟议13/4/4个A1-dev来源组清单仅为弱独立开发方案（454/278/83张原图），不叫完全独立监督，且要先检查类别和三态样本覆盖后才能定稿。
