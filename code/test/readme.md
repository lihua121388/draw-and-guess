## 一、研究目标

本项目拟提出一种面向无人机RGB航拍图像小目标检测的改进算法NSCR-YOLO。

- 基准网络：YOLO11n
- 研究数据集：VisDrone2019-DET、AI-TOD-v2
- 研究目标：提高复杂背景与密集场景下的小目标检测精度，形成可用于EI论文投稿的原创候选方法
- 开发要求：实现难度适中、计算开销可控、实验可复现

本项目不涉及红外、RGB-IR融合等多模态任务。

## 二、核心研究问题

无人机航拍图像中的目标具有尺度小、空间分布不均、相邻目标密集和背景复杂等特点。

现有多尺度融合网络通常通过固定卷积或者动态注意力整合不同范围的上下文信息，但对目标之间空间关系的显式利用仍值得研究。

本项目提出以下研究假设：

1. 在密集目标区域，过宽的上下文可能引入邻近目标的特征干扰。
2. 在稀疏目标区域，更宽的上下文可能提高弱小目标的判别能力。
3. 利用真实目标框计算目标间距，并将其作为感受野选择的辅助监督，有可能改善网络对不同目标分布的适应性。

上述假设需要实验验证，不应预先作为已成立的结论。

## 三、拟提出的原创候选模块

**NSCR：Neighbor-Spacing Conditioned Receptive-Field Routing**

中文名称：邻近目标间距引导的感受野路由模块。

### 3.1 模块输入

接收YOLO11n的两个尺度特征：

- P2：保留微小目标的浅层细节。
- P3：提供较强的语义和局部上下文。

将P3上采样至P2分辨率，经过轻量特征融合，得到统一特征F。

### 3.2 双感受野提取

设计两个并行分支：

- 局部分支：3×3深度卷积，扩张率为1。
- 宽域分支：3×3深度卷积，扩张率为3。

分别生成局部特征F_L与宽域特征F_W。

### 3.3 空间路由

通过轻量门控网络，根据输入特征生成空间权重G。

输出特征形式：

`F_out = F + γ × φ((1-G) × F_L + G × F_W)`

其中：

- G接近0时，偏向局部分支。
- G接近1时，偏向宽域分支。
- γ为残差缩放系数。
- φ为轻量特征投影。

### 3.4 邻近间距辅助监督

从训练集已有目标框中提取目标中心、尺寸和最近邻距离。

定义每个目标的尺度归一化最近邻间距：

`q_i = min_j ||c_i-c_j|| / (0.5(s_i+s_j)+ε)`

其中，`s_i = sqrt(w_i × h_i)`。

利用该间距构建软监督标签：

`t_i = sigmoid((q_i-τ)/T)`

目标较密集时，监督权重倾向局部分支；目标较稀疏时，监督权重倾向宽域分支。

采用辅助损失：

`L_total = L_YOLO + λ × L_spacing`

辅助损失只在具有有效间距定义的微小目标处计算；单目标图像、忽略区域及无效标注应合理屏蔽。

### 3.5 推理要求

真实目标框和目标间距只用于训练阶段。

推理时：

- 只输入RGB图像。
- 门控权重由图像特征自主预测。
- 不进行目标间距的真实标注计算。
- 不需要新增传感器或人工标签。

## 四、YOLO11网络修改要求

保持原YOLO11n Backbone主体不变。

新增P2检测分支，并将NSCR布置在P2与P3特征融合区域。

初期保留原P3/P4/P5检测分支，形成P2/P3/P4/P5四尺度检测结构。

第一版不修改原始目标检测损失、标签分配器和主干卷积结构。

除NSCR外，不额外引入SPD-Conv、CBAM、CARAFE、NWD等模块，以保证实验能够验证NSCR的独立贡献。

## 五、实验设计

主要消融实验：

| 编号 | 模型 | 研究目的 |
|---|---|---|
| E0 | YOLO11n | 原始基线 |
| E1 | YOLO11n + P2 | 检查P2检测头收益 |
| E2 | E1 + 单分支卷积 | 排除额外参数量的影响 |
| E3 | E1 + 无监督双分支门控 | 验证普通感受野融合 |
| E4 | E3 + 邻近间距监督 | 验证NSCR核心机制 |
| E5 | E4 + 随机打乱间距标签 | 验证空间间距信息是否有效 |
| E6 | E3 + 常规密度图监督 | 与已有密度引导思想比较 |

还应增加不同目标密度场景的分组实验，分析密集和稀疏目标区域的召回率、定位误差及特征门控差异。

## 六、评价指标

需要报告：

- mAP50
- mAP50:95
- AP-small、AR-small
- Precision、Recall
- Params、GFLOPs
- 实际GPU推理延迟和FPS

对于VisDrone和AI-TOD-v2，必须遵循可复现的数据集划分和评价协议。

训练时目标间距应基于经过图像增强后的真实标注框计算，避免坐标不一致和数据泄漏。

## 七、原创性与研究风险

现有研究已经提出动态感受野、密度感知注意力及多尺度卷积。

因此本项目不能将双分支卷积、Softmax或Sigmoid门控本身作为首次提出的创新。

主要候选创新点是：

**采用尺度归一化的实例最近邻间距，对局部与宽域上下文选择进行显式训练监督。**

需要证明：

1. 该监督确实优于无监督动态门控。
2. 相对间距比随机标签和普通密度监督更有效。
3. 改进确实发生在研究假设所涉及的目标分布场景中。
4. 新增计算量能够被实际检测收益合理支撑。

如果实验没有证明上述贡献，必须如实调整研究方案，不得将模块组合本身视为原创性证据。
