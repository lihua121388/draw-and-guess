# 全局—局部互补质量：待验证候选设计

本文件只定义未来实验，不训练质量预测器。本阶段ROI固定为S2清单，全局M0不变；B1—B4和MRU融合移植均是已有思想的对照。当前不能据此宣称原创机制或预测收益。

## 已有方法与实质区别审查

[MRU-YOLO论文](https://doi.org/10.3390/rs18162680)按区域学习重观察增量价值，再以来源感知规则融合。其[官方代码](https://github.com/JiajunChen223/MRU-YOLO/blob/main/dla_yolo/mru/validator.py)已有局部尺度限制、置信度缩放和可靠全局框保护。因此这些操作以及“只重观察有价值区域”不属于本项目原创。

[Learning NMS，CVPR2017](https://openaccess.thecvf.com/content_cvpr_2017/html/Hosang_Learning_Non-Maximum_Suppression_CVPR_2017_paper.html)已经学习检测间的关系和去重。[Seeing without Looking，CVPR2020](https://openaccess.thecvf.com/content_CVPR_2020/papers/Pato_Seeing_without_Looking_Contextual_Rescoring_of_Object_Detections_for_AP_CVPR_2020_paper.pdf)已经使用检测置信度、类别和位置等非视觉信息重新评分。通用MLP加这些特征本身也没有充分原创性依据。

本项目可检验的具体问题：对同一冻结ROI预算，局部框的“目标质量”和“加入现有全局集合后的净收益”是否存在系统差异；预测这种条件净收益是否比普通质量评分更能保留新增极小TP并降低FP/替换损害。与MRU的候选区别在于固定ROI后的实例级有符号加入收益与替换风险；这是对已有增量价值思想的细化，是否构成实质创新仍未知，不能仅靠粒度不同宣称原创。查新覆盖上述直接相关来源，不是完整专利/文献新颖性证明。

[SAHI](https://arxiv.org/abs/2202.06934)已经包含裁剪推理和裁剪微调，本阶段A也首先属于合理技术对照。[IoU-Net](https://www.ecva.net/papers/eccv_2018/papers_ECCV/html/Borui_Jiang_Acquisition_of_Localization_ECCV_2018_paper.php)已研究定位质量与分类置信度不一致；[Box Size Confidence Bias，WACV2023](https://openaccess.thecvf.com/content/WACV2023/html/Gilg_The_Box_Size_Confidence_Bias_Harms_Your_Object_Detector_WACV_2023_paper.html)表明框尺寸与置信度校准值得单独检查。因此应把“普通定位质量预测/按尺寸校准”作为对照，不能把几何特征重评分视为已证明的新方法。

## 输入与数学定义

全局集合G、固定ROI局部集合L、局部候选i=(b_i,p_i,c_i)。所有尺度为原图坐标，严禁使用GT作为推理输入。

特征z_i预定义：logit(p_i)、10维类别one-hot、log(面积/640²)、log长宽比；内部ROI边缘归一化最小距离d_i/640及边缘是否存在标志；与全局同类/任意类别最大IoU、对应全局置信度、局部与全局置信度差、最大任意IoU框类别是否一致；同类全局邻近框中心距离除以sqrt(area_i)、邻近框最大置信度；新增覆盖量u_i=1-max_j IoU(b_i,g_j)；同/跨ROI同类重叠候选数(IoU>.5)和最大置信度。u_i是预测空间新颖性代理，不能当成真实新增目标证据。孤立局部框可能是真小目标，也可能是背景FP，不采用“无全局支持即删除”的规则。

对每个局部候选，使用训练侧GT Y构造：D0=NMS_0.7(G,max500)，Di=NMS_0.7(G∪{i},max500)。评分阈值固定.001；类别感知、一对一匹配，在τ∈{.50,.55,…,.95}计算TP_τ和FP_τ。令

ΔT_i=mean_τ[TP_τ(Di,Y)-TP_τ(D0,Y)]，ΔF_i=mean_τ[FP_τ(Di,Y)-FP_τ(D0,Y)]。

监督标签y_i^gain=max(ΔT_i,0)，y_i^harm=max(-ΔT_i,0)+0.25 max(ΔF_i,0)。0.25只是预注册候选惩罚，须在独立训练开发集确认，不在548验证集选。忽略区域中的候选没有质量标签，loss屏蔽。多阈值匹配提供定位质量因素。候选加入可能NMS掉多个相邻框或挤出top500，ΔT不假设限制在[-1,1]。

双输出轻量模型fθ(z_i)=(bhat_i,hhat_i)，采用log1p标签后SmoothL1：L=mean_valid[SL1(log1p(bhat),log1p(y^gain))+SL1(log1p(hhat),log1p(y^harm))]。输出用softplus保证非负。另设常规候选正确性/多IoU质量单输出模型作为必要对照，避免把普通重评分收益误归因于条件标签。

拟定推理分数s_i=σ(logit(p_i)+α bhat_i−β hhat_i)，α、β仅由训练开发数据确定。全局分数保持；局部评分后同类统一NMS .7和max500。统计增量TP、FP、替换导致的GT丢失，不只看AP。没有训练质量器前，不提供E1/E3“新机制”数值。

第一候选实现限定为标准化特征→Linear(32)→SiLU→Linear(16)→SiLU→Linear(2)，连续特征统计只在质量器train拟合，one-hot不归一化。参数量约几千，不接入检测器Backbone/Neck。容量匹配普通质量器用相同隐藏层、两输出（质量和错误风险）以避免容量差；另用逻辑回归作线性关系对照。各模型都暂不训练。

训练标签构造可能昂贵：每个i需要一次受控插入、NMS/top500和多IoU匹配，不能把推理MLP轻量等同于离线标签生成免费。未来首先在训练侧计时，再考虑缓存全局匹配与仅更新冲突框；任何优化必须与完整定义数值一致。可按源图分层采样候选并记录抽样概率，对背景负例做逆概率权重；抽样标准只能来自训练预测/训练标签，不能看验证表现。推理仍对同一完整局部池评分，额外关系计算、特征提取和CPU/GPU传输均计入实际E2E。

独立加入标签不反映多个局部框同时加入的集合相互作用。因此它只是代理监督，可能高估重复候选价值。先用统一NMS控制重复，并报告失配；若后续再研究集合损失，需要另立预注册实验，当前不加入复杂结构。

## 数据与泄漏约束

未来质量标签必须来自官方训练图的原始、未中性遮挡RGB推理以及训练GT。不能从局部训练PNG的中性填充区域学习人工背景。训练图按源序列分组切分质量器train/dev；同原图所有ROI、增强版本和候选必须在同组。预测器只能用train拟合，超参数只能用dev选择；验证GT只计算最终指标。

特别限制：冻结M0已训练全部官方train，因此源训练划出的dev并非M0未见数据。它仅隔离局部微调/质量器的优化和模型选择，不能称为完全独立泛化集。若要更严格的质量器开发协议，后续需授权交叉拟合或另留M0从未训练的开发数据，当前不额外训练。

## 预注册消融

1. B0原NMS、B1单纯缩放、B2边缘、B3全局保护、B4联合；MRU公开hybrid参数移植为额外成熟对照。
2. 单输出普通质量器，仅局部置信度/几何；加入全局关系特征，标签不变。
3. 相同模型容量和全部关系特征，对比普通质量标签与上述条件收益/损害标签。
4. 条件模型去掉全局特征、去掉边界/ROI重复特征、去掉损害输出；标签随机打乱负对照（后续授权才训练）。
5. 至少3个质量器种子，报告dev校准和独立验证AP，按原图尺寸分组以及新增TP/丢失全局TP分组。先固定αβ，再一次性评估验证集。

只在条件标签稳定胜过容量匹配普通质量器、成熟B4、MRU移植，而且极小新增TP保留/替换损害符合假设时，才讨论该机制的贡献。原论文MRU完整管线的公开结果和本项目的固定ROI移植使用不同模型、预算/输出上限，不能直接把数值差当成算法优劣。

## A/B因子接口

E0=A0+B0；E1=A0+成熟B4；E2=A1+B0；E3=A1+同一成熟B4。B为候选学习机制时必须另标E1-Q/E3-Q并注明训练数据/权重/参数哈希，不能沿用成熟B4名称。`evaluate_local_factors.py`当前实现成熟融合接口，不训练质量器。

全局预测、548ROI清单和评价不变。正式局部模型未训练前E2/E3为空，不把dry-run当成训练结果。候选质量器未训练前E1-Q/E3-Q为空。离线融合只能测CPU重融合耗时和引用历史GPU成本；新的完整E2E延迟须另运行完整流程计时，不能把缓存时间当检测延迟。
