## 固定规则

- 同一份M0权重与548张VisDrone验证图像，FP32，无训练，无结构/权重/标注修改。
- 全局分支与S0一致：val兼容640、维持原batch8矩形形状，逐图执行和计时；五组重新执行全局推理，最终核验全局预测逐图完全相同。
- 选区只读取全局最终max500预测，conf≥0.10、原图sqrt(wh)<32。选区信号类无关NMS=0.7以避免多类别候选重复计权；它不改变实际检测输出。
- 原图ROI640×640，候选来自固定20%网格及预测框中心/角点，内部边缘安全距离8px；按新增完整覆盖预测框置信度总和贪心选择，平局按新增框数、坐标排序。参数在测试前固定。
- 没有有效预测/新增收益时少选ROI，记录实际数量，不重复窗口凑预算。Top-1是Top-2的首个窗口。
- S3/S4使用已有GT Oracle几何算法，独立标注，仅作潜力诊断，GT不写入检测框、不修正预测类别或置信度。
- 最低预测conf=0.001，ROI内NMS=0.7，中间候选上限30000/输出10000；全局max500输出与ROI结果一起按原图坐标类别感知NMS=0.7，最终每图max500。
- 计时包含完整解码、全局检测、选区、裁剪、局部检测、坐标恢复、融合；不包含模型加载、预热、JSON归档和评分。各组实际独立执行。
