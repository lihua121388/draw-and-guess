# NSCR 设计审查与论文材料

查阅日期：2026-10-10。以下是公开一手资料的初步对照，不是完整的新颖性检索结论。

## 与已有工作的关系

| 工作 | 已有机制 | 本项目需验证的区别 |
|---|---|---|
| [Selective Kernel Networks, CVPR 2019](https://arxiv.org/abs/1903.06586) | 多核分支和自适应选择权重，说明动态感受野选择已有基础 | NSCR 的候选贡献在实例间距软标签对空间门控的直接监督，而非并行卷积或门控形式 |
| [LSKNet, ICCV 2023](https://arxiv.org/abs/2303.09030) | 遥感检测中动态选择较大空间感受野，利用对象所需上下文差异 | “遥感目标需要动态上下文”本身不是新贡献；需证明间距监督比无监督门控更有效 |
| [DMNet, CVPRW 2020](https://arxiv.org/abs/2004.05520) | 利用密度图引导航拍图像裁图与检测 | NSCR 不在推理使用密度图裁图，而将尺度归一化实例关系作为训练期路由监督 |
| [CDMNet, ICCVW 2021](https://openaccess.thecvf.com/content/ICCV2021W/VisDrone/html/Duan_Coarse-Grained_Density_Map_Guided_Object_Detection_in_Aerial_Images_ICCVW_2021_paper.html) | 粗粒度密度估计、区域聚合和裁图 | E6 控制监督信息来源，比较密度与相对间距；不是对该论文网络的完整重现 |

从这些资料可以推断监督信号是值得检验的区别，但不能据此断言没有其他论文使用最近邻关系或间距辅助监督。投稿前应扩展检索 “nearest-neighbor spacing / instance separation / context selection supervision / crowd-aware receptive field”等关键词，并核对公式、监督位置和任务设定。

## 数学与工程审查

尺度归一化 q 对共同平移和等比缩放不变；对非等比变换并不严格不变，因此根据增强后的框重新计算。T>0 控制软标签梯度，τ 控制局部/宽域分界。训练中标签不需要梯度，门控使用 BCEWithLogits 保持 AMP 下的数值稳定。

公式的最小值作用于归一化距离，尺度很大的邻居可能比欧氏最近邻得到更小 q。此定义遵循需求，但论文应称为“最小尺度归一化间距”，或在附加实验比较两种定义。重叠目标、截断框和同中心实例也可能造成 q≈0，应检查其标签分布，而非认定小 q 总意味着上下文有害。

宽域分支采样 dilation=3，不保证所有宽域上下文都有效；其稀疏采样可能漏掉某些局部信息。门控使用同一空间标量作用于所有通道，优先保证轻量，不能据此解释为逐通道语义选择。残差 γ 可能学到接近零，必须查看 γ 和门控分布，以检验模型是否实际使用路由机制。

双线性中心采样让微小框也有明确监督位置，但密集实例共享网格时标签会冲突。实现采用逐实例损失并按图均衡，冲突仍是分辨率限制。只监督 sqrt(area)≤32 的目标会使监督数量随增强变化；应报告每 epoch 有效监督实例数，并比较不同 small_size。

P2 分支通常比两条深度卷积本身更影响 FLOPs 和显存。E1−E0 检验 P2，E3−E1 检验动态路由，E4−E3 检验间距监督。E2 的局部模块参数预算与 E3 接近，但不能只用总参数量认定计算或容量完全匹配，应同时比较 GFLOPs 与实测延迟。

## 可直接使用的方法章节草稿

针对无人机 RGB 航拍目标的尺度与空间分布差异，本文研究相邻实例关系对局部上下文选择的影响。在保持 YOLO11n 主干和原有三尺度特征路径的基础上，增加 P2 检测分支，将 P3 特征上采样后与 P2 进行轻量融合。融合特征分别通过扩张率 1 和 3 的深度卷积形成局部与宽域表示，空间门控对两者加权，并经投影与可学习残差缩放返回融合特征。

训练期间，仅利用增强后已有目标框构建尺度归一化的实例间距软标签。该标签不依赖额外人工标注，不跨图像计算，不使用验证或测试框。辅助目标鼓励路由权重与预设空间关系假设一致，但目标密集时局部上下文是否更优仍由消融实验检验。推理期间，权重由 RGB 特征自主生成，不计算真实框间距。

## 实验章节与待填结果

主实验使用 VisDrone2019-DET 官方划分和 AI-TOD-v2 官方 COCO 划分。首轮选择完整 VisDrone（6471 张 train，548 张 val）作为适中规模数据集；训练分辨率 640、batch=8、AdamW、学习率 0.001、余弦衰减、100 epochs、AMP，种子 42/43/44。全部消融采用相同数据与增强参数。以验证集选择权重，以固定设置评价 test-dev；AI-TOD-v2 的类别与 tiny 指标由官方标注和评估器定义。

结果分析应至少回答：E4 是否稳定优于 E3；是否优于 E5 与 E6；收益是否集中在预期密度组；稀疏区域宽域门控是否更大；密集区域定位误差是否降低；额外延迟与精度收益是否合理。报告每种子值和均值±标准差；结论没有数据支持时保留为空。

如果 E4 与 E3 接近，不能将路由监督描述为有效；如果 E5 与 E4 接近，应考虑标签分布正则化而非空间对应关系；如果 E6 更好，应如实讨论密度信号的优势。当前仅完成实现与流程验证，尚无证据证明检测提升、原创性或 EI 录用。
